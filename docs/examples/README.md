# Generated demonstration gallery

The eight PNG files in this directory are original generated demonstrations
for the public README. They prove two equal image-native title-system families:

- `oceanographic-title-system`, `treasure-chart-title-system`,
  `board-game-title-system`, and `botanical-specimen-title-system` demonstrate
  **material-world** construction.
- `title-map-secretary-chi`, `hero-wordmark-secretary-chi`,
  `japanese-title-shachoshitsu-no-asa`, and `tsundere-secretary-chi` demonstrate
  **character-led** construction. They use the repository author's own
  Secretary Chi character references with that owner's authorization.

They are not third-party album artwork, artist-specific defaults, or assets a
skill user should copy. Reuse the construction relationship, not a title,
character, palette, motif, or composition.
