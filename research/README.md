# Research archive

This folder preserves the bounded precedent work that informed the project. It
is not loaded during an ordinary cover run and is not a menu of styles to
reproduce. The runtime source of truth is
[`skills/album-cover-director/`](../skills/album-cover-director/): start with
the two image-native title-system families, then use research only to solve a
specific unresolved construction problem.

The repository contains observations and source links only; it contains no
third-party album-cover images.
